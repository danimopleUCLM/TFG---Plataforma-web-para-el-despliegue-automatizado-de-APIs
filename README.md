# Plataforma Web para el Despliegue Automatizado de APIs en Entornos Cloud e Híbridos

> **Trabajo Fin de Grado (TFG)** — Grado en Ingeniería Informática  
> Universidad de Castilla-La Mancha (UCLM) — Facultad de Ciencias Sociales y Tecnologías de la Información (Talavera de la Reina)

## Descripción

Plataforma web (*Internal Developer Platform*) orientada a simplificar, estandarizar y automatizar el ciclo de despliegue de APIs alojadas en repositorios de GitHub sobre entornos locales de simulación y proveedores de nube pública.

### Características principales

- **Despliegue automatizado e híbrido:** empaquetado de servicios en contenedores y aprovisionamiento reproducible mediante Infraestructura como Código (IaC) sobre entornos locales y multi-cloud.
- **Modo de configuración manual:** panel web guiado que abstrae los parámetros de red, recursos, variables de entorno y escalado.
- **Modo asistido por IA (MCP):** agente conversacional basado en *Model Context Protocol* capaz de inspeccionar repositorios, traducir peticiones en lenguaje natural a configuraciones válidas y ejecutar despliegues bajo confirmación del usuario.
- **Observabilidad y métricas:** panel centralizado para supervisar el estado de los despliegues y el rendimiento de las APIs en ejecución.
